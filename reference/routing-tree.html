Disclosure routing tree

You found a flaw in an AI or agentic system. Where does it go? Nine destinations resolve and none of them publishes a procedure telling a reporter which to use. This tree is built from each destination's own stated scope, so treat it as a starting position for argument rather than as established practice.

Walk it

The most common routing error is treating every AI-related finding as an AI flaw. A memory-safety bug in an inference server is an ordinary software vulnerability that happens to live in AI infrastructure, and it routes like any other CVE.

The whole tree at once

The hard case

The ExploitGym escape needed at least three routes at once. It was a Branch A defect, with a zero-day in a package registry cache proxy and a fixable vendor. It was a Branch C runtime failure, with an agent pursuing an unintended goal across five trust boundaries. It was arguably a Branch B behavioural flaw, because the agent was gaming its specification. No single destination would have captured it. The capstone routes it end to end.

Three things the tree makes visible

One flaw often needs several routes. The tree is not a switch. Branch C routes to two destinations at once, because the identifier system and the behavioural record system are separate and neither one subsumes the other.

Two terminals cannot yet be evaluated. Akrites has no post-launch outcome data and FLARE-AI publishes no adoption numbers. Anyone choosing between them in 2026 is choosing on stated intent.

No terminal accepts an agent runtime flaw natively. Branch C works by decomposing the flaw into parts that existing systems can accept, and that decomposition loses the thing that made it an agent flaw in the first place. This is the strongest argument in the course for why the CWE AI Working Group's corpus gap matters. Without weakness classes that describe agent failures, there is nothing for a record to point at.

Not to be confused with prioritization. The SSVC decision track published by the AIVSS project answers how urgently to act. This tree answers where to send it. The two are complementary and should not be blended together.
